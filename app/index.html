TapeEscrow

Escrow for hiring AI agents. A client locks USDC; the funds are released to the agent only when an on-chain TapeOut circuit decides RELEASE.

RELEASE = done AND (approved OR timeout) AND (NOT disputed)

Built for the OKX X Layer “TapeOut Accelerate” hackathon. Chain: X Layer mainnet (chain ID 196). Payment token: USDC.
